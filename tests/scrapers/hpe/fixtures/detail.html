HPESBNW05119 rev.1 - Multiple Vulnerabilities in HPE Aruba Networking Private 5G Core

Document Subtype: Security Bulletin Document ID: hpesbnw05119en_us Last Updated: 2026-08-07 Release Date: 2026-08-07 Document Version: 1

Potential Security Impact: Remote access restriction bypass

Source: Hewlett Packard Enterprise, HPE Product Security Response Team

VULNERABILITY SUMMARY

NOTE: A signed text copy is available at CSAF text.

Summary

HPE has released a patch for two security vulnerabilities.

Affected Products

HPE Private 5G Core 1.26.1.2 and below

Unaffected Products

HPE Private 5G Core 1.26.1.3 and above

Details

Authentication bypass (CVE-2026-54763)

Internal Reference: VULN-715
Severity: Critical
CVSS v3.1 Base Score: 10.0
CVSS v3.1 Vector: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:C/C:H/I:H/A:N

Privilege escalation (CVE-2026-33377)

Internal Reference: VULN-716
Severity: High
CVSS v3.1 Base Score: 7.1
CVSS v3.1 Vector: CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:H/A:N

Workaround

Restrict management interfaces to trusted networks.

Exploitation and Public Discussion

HPE is aware of public discussion of CVE-2026-54763.

References:
  • CVE-2026-54763
