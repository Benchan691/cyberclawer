FGFM Authentication Weakening via CLI Configuration

Summary

An Authentication Bypass Using an Alternate Path or Channel [CWE-288] vulnerability in FortiManager and FortiManager Cloud may allow a remote unauthenticated attacker to impersonate any FortiGate managed by the FortiManager with a specific CLI option set via crafted FGFM requests if the attacker has a valid certificate.

Version Affected Solution
FortiManager 8.0 Not affected Not Applicable
FortiManager 7.6 7.6.1 Upgrade to 7.6.2 or above
FortiManager 7.4 7.4.3 through 7.4.5 Upgrade to 7.4.6 or above
FortiManager 7.2 7.2.5 through 7.2.9 Upgrade to 7.2.10 or above
FortiManager Cloud 7.6 7.6.1 Upgrade to 7.6.2 or above
FortiManager Cloud 7.4 7.4.3 through 7.4.5 Upgrade to 7.4.6 or above
FortiManager Cloud 7.2 7.2.5 through 7.2.9 Upgrade to 7.2.10 or above

As workaround fgfm-peercert-withoutsn should be disabled :

config system global
set fgfm-peercert-withoutsn disable
end
